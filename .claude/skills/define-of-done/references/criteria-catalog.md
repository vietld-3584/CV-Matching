# 完了基準 AIドラフト提案カタログ

`define-of-done.md` §2「カテゴリの目安」の6カテゴリごとに、ユーザーが基準を出せない場合にAIがどんな根拠からドラフトを提案するかをまとめる。**すべて「ドラフト（要確認）」として提示し、ユーザーの承認を得てから確定値にする**（無断で基準を確定しない）。

根拠として参照する情報源：`docs/01_management/overview.md`（§1契約形態・§4対応範囲・役割分担）、`docs/02_requirements/function-list.md`（優先度別件数）、`docs/02_requirements/non-function-list.md`（カテゴリ別件数）、`docs/01_management/stakeholders.md`（§2体制）。

## 機能要件

**着眼点**: `function-list.md` の優先度分布（必須／推奨／任意／対象外の件数）、対象外機能の有無。

**ドラフト例**:
- 優先度「必須」がほとんど → 「優先度『必須』の全機能が受入テストに合格していること」
- 優先度「推奨」以下も多い → 「優先度『必須』『推奨』の機能が受入テストに合格していること（『任意』は次フェーズへの持出しを許容）」

## 非機能要件（品質・性能）

**着眼点**: `non-function-list.md` のカテゴリ別件数・優先度、数値目標の有無。

**ドラフト例**:
- 数値目標が明記されているカテゴリ → 「〇〇カテゴリの全項目が目標値・基準を満たしていること（検証方法：non-function-list.md記載の方法に準拠）」
- 数値目標が未確定のカテゴリが多い → 「目標値が未確定の項目は運用開始後の実測で判定するため、クロージング時点では対象外とする」提案を添える

## ドキュメント・成果物

**着眼点**: 契約形態（`overview.md` §1）に成果物の記載があるか、`overview.md` §4の「ドキュメント作成」行の実施者。

**ドラフト例**:
- 請負契約で成果物リストが契約書にある → 「契約書記載の成果物（設計書・マニュアル等）一式が納品されていること」
- ラボ型・SES契約 → 「契約上の成果物義務はないため、開発時に作成したドキュメント（設計メモ・引き継ぎ資料等）が整備されていること」
- ドキュメント作成の実施者がクライアント側 → このカテゴリを対象外、または「Sun*側が作成する範囲のドキュメントのみ」に限定する提案

## テスト・受入

**着眼点**: `overview.md` §4の「受入テスト（UAT）」実施者、契約書に検収条件の記載があるか。

**ドラフト例**:
- UAT実施者がクライアント → 「単体/結合/システムテストがSun*側で完了し、UATでクライアントの検収合格（重大バグ0件）を得ていること」
- UAT実施者がSun* → 「Sun*側で単体〜受入まで全テストを完了し、テスト結果報告書をクライアントが承認していること」

## 運用移行・引き継ぎ

**着眼点**: `overview.md` §4の「リリース後の運用・保守」「障害対応（本番）」の実施者。

**ドラフト例**:
- 運用・保守がクライアント側に引き継がれる → 「運用手順書・監視設定・障害対応フローの引き継ぎが完了し、クライアント側で運用開始できる状態であること」
- Sun*側が継続して運用・保守を担う（別契約に移行） → 「運用・保守フェーズへの契約切り替え、体制引き継ぎが完了していること」
- 対象外（社内ツール等で運用移行が発生しない） → このカテゴリを§2から対象外とする提案（Block Cで判断）

## 契約・請求

**着眼点**: `overview.md` §1の契約形態（準委任／請負／SES）。

**ドラフト例**:
- 請負契約 → 「契約範囲の作業が完了し、検収書をクライアントから受領していること」
- 準委任・SES契約 → 「契約期間中の稼働報告がすべてクライアントに承認され、請求処理が完了していること」（検収書ではなく稼働報告承認を基準にする）

## 提示時の共通ルール

- 各カテゴリのドラフトは「〇〇という基準でよいか、それとも別の基準があるか」の確認形式で提示する
- ユーザーが「わからない・後で決める」と回答した場合は、基準セルを空欄のまま残し、Skill実行の完了サマリで未確定事項として報告する（AIが独断で基準を確定しない）
- 該当性が低いカテゴリ（例：社内ツールで運用移行・引き継ぎの懸念がほぼない）は、対象外である旨を一言添えて省略してよい（Block Cで§2から対象外とした場合はこのカテゴリのドラフト提案自体を行わない）
