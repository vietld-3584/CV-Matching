## 2. 優先度の判定基準

<!-- 影響度・緊急度から優先度を判定する目安表。プロジェクトの特性に応じて調整してください -->

| 優先度 | 目安 |
| --- | --- |
| 高 | 即対応が必要。進行中の作業・リリースに直接影響する |
| 中 | 早期対応が必要だが、即時のブロッカーではない |
| 低 | 影響は小さく、計画的に対応すればよい |

## 3. ステータスの定義

<!-- プロジェクトの特性に応じて調整してください -->

| ステータス | 意味 |
| --- | --- |
| 未対応 | 課題として登録済みだが、対応方針・担当者が未確定 |
| 対応中 | 対応方針が確定し、担当者が対応を進めている |
| 対応済み | 対応が完了し、内容を確認済み |
| 保留 | 優先度・状況等の理由により、対応を一時的に見送っている |
