## 3. ステータスの定義

<!-- プロジェクトの特性に応じて調整してください -->

| ステータス | 意味 |
| --- | --- |
| 監視中 | リスクとして識別済みだが未発生。定期的に発生確率・影響度を監視している |
| 発生（課題化） | リスクが顕在化し、`problem-list.md` に課題として登録済み |
| 解消 | 対応策の実施等によりリスクが解消され、監視対象から外れた |
| 対応不要 | 影響が軽微、または状況変化によりリスクとして扱う必要がなくなった |
