# 進捗状況

> 本ドキュメントは、[`schedule.md`](./schedule.md) のベースライン計画（前提条件・マイルストーン・WBS）に対する**現在の進捗**を追跡するためのものです。
> `schedule.md` は計画（予定日）を変更しないベースラインとして維持し、実績・ステータスの更新は本ファイルに記載してください。マイルストーン/WBSのIDは `schedule.md` と一致させてください。
> **対計画差異**列は `schedule.md` の予定日（マイルストーンは「予定日」、WBSは「終了日（予定）」）と本ファイルの実績（または本日時点で未完了の場合は現在日）を比較した**結論のみ**を記載してください（例: `順調` / `3日遅延` / `2日前倒し`）。予定日そのものは `schedule.md` を参照し、本ファイルに複製しないでください。
> AIエージェント（PM）は本ファイルを読み込むことで、プロジェクトの最新の進捗状況（計画に対する遅れ・前倒しを含む）を把握できます。週次の状況は [`reports/`](./reports/yyyy-mm-dd-weekly-report.md) にスナップショットとして別途記録してください。
