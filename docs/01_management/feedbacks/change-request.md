# 変更依頼 (Change Request) 一覧

> 本ドキュメントは、クライアントまたは自社（Sun*）から提起された、スコープ・スケジュール・予算に影響を及ぼす変更依頼を記録し、対応状況を追跡するためのものです。
> 日常的な意見・気づきは [`feedback-list.md`](./feedback-list.md) を参照してください。変更依頼の採用が決まった場合は [`../decision.md`](../decision.md) にも決定事項として記録し、スケジュールへの影響が確定した場合は [`../schedule.md`](../schedule.md) を更新してください。

## 2. ステータスの定義

| ステータス | 定義 |
| --- | --- |
| 受領 | 変更依頼を受領し、影響調査前の状態 |
| 調査中 | 影響範囲（スコープ・スケジュール・予算）を調査中 |
| 承認待ち | 見積・影響範囲を提示し、クライアントの承認待ち |
| 承認済み | クライアントが承認し、対応を開始できる状態 |
| 却下 | 対応しないことが決定した状態（理由を「対応方針」欄に記載） |
| 対応完了 | 変更依頼への対応が完了した状態 |

## 3. 記録時の注意事項

<!-- クライアントとの認識齟齬を防ぐための運用ルール。プロジェクトの特性に応じて調整してください -->

- 変更依頼の影響（スコープ・スケジュール・予算）は、対応方針を提示する前に必ず調査し、クライアントに合意を得てください。
- 承認・却下の決定は [`../stakeholders.md`](../stakeholders.md) の「3. 意思決定・承認フロー」に定める権限者が行ってください。
- スケジュール・予算に影響する変更依頼が承認された場合は、[`../decision.md`](../decision.md) に決定事項として記録し、[`../schedule.md`](../schedule.md) を更新してください。
