# テストスケジュール

> 本ドキュメントは、テストのマイルストーン・WBS（Epic単位のテストタスク）をまとめたベースラインプランです。
> 全体スケジュールは [`../01_management/schedule.md`](../01_management/schedule.md) を参照し、WBS IDは同ファイルのEpic/Story IDと対応させてください。計画は基本的にリプランが発生した場合のみ更新し、日々の進捗・実績は [`../01_management/progress.md`](../01_management/progress.md) を参照・更新してください。
> 本プロジェクトはEpic単位でイテレーティブに開発するため、テストも各Epicの実装完了ごとに「手動テストケース作成 → 手動テスト実施 → バグ修正」を繰り返します。プロジェクト全体を通した1回きりのテストフェーズではない点に注意してください。
