### Background and Purpose

- イベント掲載の操作性を上げ、担当者が迷いなく、使い心地よくイベント掲載をできるようにしたい。
- 掲載内容を編集したい場合に操作や画面の行き来をわかりやすくしたい。
- 掲載設定内容が不正だった場合にアラートを出し、問題ない状態で掲載できるようにしたい。

### Expected Impact

- イベント掲載の体験がよくなることで、「使いにくい」とストレスを感じて離脱したり使用頻度が低くなっているユーザーの使用頻度が上がる
- 担当者の使用頻度の高いイベント掲載でよいUXが体験できることで、サービスの他の機能も使ってもらえるようになる

### Feature Description

- 担当者として、イベント掲載をサクサク進めたい。それにより時間がかからず、効率よく参加者にイベントを案内し業務の負荷が削減できるからだ。
- 担当者として、イベント掲載の操作が分かりやすいものであってほしい。何度も使うものなのでストレスを感じずに実施したいからだ。

## User Stories
- 担当者として、イベント掲載をサクサク進めたい。それにより時間がかからず、効率よく参加者にイベントを案内し業務の負荷が削減できるからだ。
- 担当者として、イベント掲載の操作が分かりやすいものであってほしい。何度も使うものなのでストレスを感じずに実施したいからだ。
