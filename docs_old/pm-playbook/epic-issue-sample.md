## 変更詳細

### N-1: 表示切替タブ + ピックアップイベントリスト（セクション3, 10）

- セグメントコントロール形式の2タブ（初期: 通常検索）
- タブ切替時: 開催地域・カテゴリは保持、キーワードはクリア
- ピックアップ: カテゴリあたり最大6件（掲載履歴2件 + 閲覧傾向で残り）
- 選定ロジック: BR担当者ピックアップイベントのロジック参照

### N-2: ブックマーク機能（セクション5.2, 6.2.2）

- イベント行にブックマークアイコン追加（登録/解除切り替え）
- 検索結果ヘッダーにブックマークのみ表示トグル（初期OFF、通常検索のみ）

### N-3: AIレコメンド対応（セクション6.2, 9, 12）

- AIレコメンド時間設定ダイアログ: 3分～15分（1分刻み）
- AIレコメンドCB → ダイアログ表示（特定カテゴリのみ）
- プログラムCB: AIレコメンドイベントでは非表示
- 掲載ボックス: 「nプログラム＋AIレコメンド」「○分～○分」表示

### N-4: 全体集客率表示（セクション5.1, 6.2）

- AIレコメンドイベントのみ表示、非AIは非表示
- 組織内1プログラム以上完了後から表示
